Undangan Digital — Petunjuk Singkat

Cara pakai:
- Buka file `ud.html` di browser (double-click atau buka via Live Server).
- Untuk menerima RSVP via WhatsApp, ganti nomor pada `script.js` di variabel `nomorWA` menjadi nomor Anda (format internasional tanpa +, contoh: 62812...)
- Untuk mengganti tanggal atau nama pasangan, edit konten di `ud.html`.
- Musik: file audio menggunakan sumber eksternal; jika tidak autoplay karena pembatasan browser, tekan tombol musik di kanan bawah.

Catatan pengembangan:
- File utama: [UNDANGAN/ud.html](UNDANGAN/ud.html)
- Styles: [UNDANGAN/style.css](UNDANGAN/style.css)
- Script: [UNDANGAN/script.js](UNDANGAN/script.js)
